## HQ Glossary

Use these English terms in HQ documentation and prompts. The **German** column gives the interface label where available and a translation elsewhere. **—** means the English term is also used in German.

### Planner objects

| Term | German | Meaning |
|---|---|---|
| **Entry** | Eintrag | The collective term for a **Task**, **Feature**, or **Fix**. |
| **Task** | Aufgabe | A unit of work that can belong to either type of Project or sit in the Inbox. |
| **Feature** | — | An Entry for a new capability or improvement in a Software Project. |
| **Fix** | — | An Entry for correcting an issue in a Software Project. |
| **Project** | Projekt | The collective term for a **Standard Project** or a **Software Project**. |
| **Standard Project** | Normales Projekt | A Project whose Entries are Tasks. |
| **Software Project** | Softwareprojekt | A Project that supports Tasks, Features, Fixes, and Releases. |
| **Release** | — | A version of a Software Project, from planning through publication. |
| **Target Version** | Zielversion | The Release assigned to an Entry. |
| **Subtask** | Unteraufgabe | A step within an Entry that can be marked complete or reopened. |
| **Acceptance Criterion** | Akzeptanzkriterium | A checkable condition that a Feature or Fix should satisfy. |
| **Predecessor** | Vorgänger | An Entry that must be completed before the current Entry can be completed. |
| **Successor** | Folgeaufgabe | An Entry that depends on the current Entry being completed. |
| **Manual Note** | Meldung | A message written by the user in an editor and displayed in History. |

### Interface

| Term | German | Meaning |
|---|---|---|
| **Navigation Sidebar** | Navigationsleiste | The left sidebar with links to the Inbox, Projects Overview, Ideas, Research, and individual Projects. |
| **Main View** | Hauptansicht | The central area showing the selected workspace section or Project. |
| **Inbox** | Posteingang | The Main View for Tasks without a Project. |
| **Projects Overview** | Projektübersicht (*Projekte*) | The Main View that lists all Projects. |
| **Project View** | Projektansicht | The Main View for a single Project. |
| **Project Tabs** | Projektregister | The tabs within a Project View. Every Project has **Status** and **Tasks** tabs. Software Projects also have **Features**, **Fixes**, and **Releases** tabs. |
| **Entry List** | Eintragsliste | The list of Entries in the Inbox or in a Project’s Tasks, Features, or Fixes tab. |
| **Details Sidebar** | Detailleiste | The right sidebar that opens when an Entry or Release is selected. |
| **Entry Details** | Eintragsdetails | The contents of the Details Sidebar for a selected Entry. |
| **Release Details** | Release-Details | The contents of the Details Sidebar for a selected Release. |
| **Entry Editor** | Eintragseditor | The dialog for creating or editing an Entry. Use **Task Editor**, **Feature Editor**, or **Fix Editor** for behavior specific to one Entry type. |
| **Project Editor** | Projekteditor | The dialog for creating or editing a Project. |
| **Release Editor** | Release-Editor | The dialog for creating or editing a Release. |
| **History** | Verlauf | The dated record of changes and Manual Notes shown in Entry Details, Release Details, and a Project’s Status tab. |

> “In Entry Details, show Acceptance Criteria below the description. In the Entry Editor, place Subtasks above Predecessors.”
